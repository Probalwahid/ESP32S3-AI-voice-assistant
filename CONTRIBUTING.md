# 🤝 Contributing to ESP32-S3 AI Voice Assistant

First off, thank you for considering contributing to this project! It's people like you that make open-source such a great community.

## 💡 How Can You Contribute?
* **Reporting Bugs:** If you find a bug, please open an issue and include details about your hardware setup and the error logs.
* **Suggesting Enhancements:** Have a great idea for a new feature? Open an issue to discuss it!
* **Submitting Pull Requests:** You can directly write code and submit a PR to improve the project.

## 🔄 Pull Request Process
1. **Fork** the repository to your own GitHub account.
2. **Clone** your forked repository to your local machine.
3. Create a new **Branch** for your feature (`git checkout -b feature/YourFeatureName`).
4. **Commit** your changes clearly (`git commit -m 'Add some feature'`).
5. **Push** to the branch (`git push origin feature/YourFeatureName`).
6. Open a **Pull Request** on this main repository.

## 📝 Code Style & Rules
* Please keep your code clean, readable, and well-commented.
* Follow the existing folder structure (e.g., keep Arduino code in `firmware/` and Python code in `backend/`).
* Do not upload any personal API keys or Wi-Fi passwords.

Thank you for your support and contributions!
